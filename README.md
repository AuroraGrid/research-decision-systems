# Hasan Kazmi — Research & Decision Systems

A clean editorial portfolio containing two public-interest research projects:

- EU Chat Control Monitor
- The Russian JFK Dossier

Israel Report is intentionally excluded from this repository.

## Design principles

- Editorial research-publication layout
- No gradients, glow effects, fake live indicators, or dashboard ornament
- Clear source hierarchy and authorship disclosure
- Responsive, accessible static HTML and CSS
- Open Graph preview images for LinkedIn and social sharing

## Deploy

This repository is ready for Vercel with no build command required. Import the repository and deploy from the root directory.
