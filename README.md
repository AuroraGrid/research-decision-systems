## Design and publication principles

- editorial research-publication layout;
- clear authorship and methodology disclosure;
- no fake live indicators, dashboard theater, or unsupported technical claims;
- responsive static HTML and CSS;
- explicit source hierarchy and analytical limits;
- Open Graph preview assets for professional sharing.
